# Honey Chain: Synthetic Smart Beehive Dataset

This repository contains a synthetic sensor dataset for **Honey Chain**, a blockchain, AI, and IoT honey traceability project. It simulates readings from sensors installed in beehives and includes a hive-condition label that can be used as an alert-prediction target.

> **Important:** The records and labels are half synthetic. They are intended for development, demonstrations, and experimentation—not for diagnosing real colonies or making beekeeping decisions. `Hive_Status` is generated by the synthesis script; it is not the output of a trained AI model.

## Files

- [`honey_bee_dataset_final.csv`](honey_bee_dataset_final.csv) — generated dataset (3,000 records).
- [`synthesize_csv.py`](synthesize_csv.py) — reproducible dataset generator.
- [`honey_bee_dataset_filtered.csv`](honey_bee_dataset_filtered.csv) — temperature and weight values used as empirical baselines.
- [`honey_bee_dataset.csv`](honey_bee_dataset.csv) — original dataset.

## Dataset schema

The final CSV has the following columns, in order:

| Column | Type | Description |
| --- | --- | --- |
| `Temperature_C` | Float | Simulated internal hive temperature in degrees Celsius. |
| `Hive_Weight_kg` | Float | Simulated total hive weight in kilograms. |
| `Sound_Level_dB` | Float | Simulated acoustic buzzing level in decibels. |
| `Hive_Status` | Category | Synthetic hive-condition label; use as the target for alert-prediction experiments. |

### Status labels

| Label | Simulated pattern |
| --- | --- |
| `Normal` | Temperature near the normal hive range, moderate steady sound, and relatively stable weight. |
| `Weak_Colony` | Lower temperature, lower sound, and comparatively low weight. |
| `Disease_Risk` | More variable temperature and sound with a lower weight baseline. |
| `Swarming_Risk` | Near-normal temperature, high buzzing, and reduced weight to represent a sudden drop. |
| `Queenless` | Variable temperature, comparatively stable weight, and elevated irregular buzzing. |

The generated class distribution is intentionally imbalanced:

| Label | Records | Share |
| --- | ---: | ---: |
| `Normal` | 1,500 | 50% |
| `Weak_Colony` | 375 | 12.5% |
| `Disease_Risk` | 375 | 12.5% |
| `Swarming_Risk` | 375 | 12.5% |
| `Queenless` | 375 | 12.5% |

Values are class-conditioned and include random variation, with some overlap between classes. The source temperature and weight observations inform the generated values, but are transformed to reflect the simulated status patterns; they are not copied unchanged into the output.

## Regenerate the dataset

The script requires Python, pandas, and NumPy. From the project directory, activate the included fish environment and run the generator:

```fish
source .venv/bin/activate.fish
python synthesize_csv.py
```

The script reads `honey_bee_dataset_filtered.csv` and writes `honey_bee_dataset_final.csv` in the same directory. Its fixed random seed (`42`) makes each run reproducible. It expects exactly 3,000 source records with columns `Temperature_C` and `Hive_Weight_kg`.
